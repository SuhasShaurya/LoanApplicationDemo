## Tab 1: 📋 Apply for Loan

### When to Use
- Submit new loan applications
- Get instant decision

### What You Do
1. Fill application form
2. Click "Submit Application"
3. See decision immediately

### What You Get
- ✅ Decision banner (Green/Red/Yellow)
- ✅ Key metrics (4 cards)
- ✅ Decision explanation
- ✅ Key factors list
- ✅ Financial details
- ✅ Download options

### Example Input
```
Applicant ID: APP001
Age: 35
Income: $85,000
Employment: Full-time
Credit Score: 760
Loan Amount: $200,000
Tenure: 360 months
Liabilities: $2,500
Location: California
```

### Example Output
```
✅ LOAN APPLICATION APPROVED!
Decision: Approve
Risk: 0.15
Confidence: 88%
Case ID: CASE-001234
```

## 🎯 Common Tasks

### Task 1: Submit a Loan Application
```
1. Go to: Tab 1 (📋 Apply for Loan)
2. Fill: Application form
3. Click: "Submit Application"
4. See: Decision immediately
5. Result: Application added to history
```

### Task 2: View Your Decision
```
1. Go to: Tab 2 (📊 View Applications)
2. Find: Your application in list
3. Click: To expand
4. Read: Decision and explanation
```

### Task 3: Find All Approved Applications
```
1. Go to: Tab 2 (📊 View Applications)
2. Filter: Uncheck "Reject" and "Review"
3. See: Only approved applications
```

### Task 4: Search for Specific Application
```
1. Go to: Tab 2 (📊 View Applications)
2. Type: Your Applicant ID in search box
3. See: Matching applications only
```

### Task 5: Download Application Report
```
1. Go to: Tab 2 (📊 View Applications)
2. Find: Your application
3. Click: To expand
4. Go to: "Report" tab
5. Click: "Download as JSON" or "Download as TXT"
```

### Task 6: Learn About System
```
1. Go to: Tab 3 (📈 Dashboard)
2. Or: Tab 4 (📖 About)
3. Read: System information
```

## 🔍 Filtering Guide (Tab 2)

### Show Only Approved
```
Uncheck: ❌ Reject, ❌ Review
Keep: ✅ Approve
Result: Only approved applications
```

### Show Only Rejected
```
Uncheck: ❌ Approve, ❌ Review
Keep: ✅ Reject
Result: Only rejected applications
```

### Show Approved + Review
```
Check: ✅ Approve, ✅ Review
Uncheck: ❌ Reject
Result: Approved and under-review applications
```

### Show All
```
Check: ✅ Approve, ✅ Reject, ✅ Review
Result: All applications
```

### Search by Applicant ID
```
Type in search: "APP001"
Result: Applications with APP001 in ID
```

### Search by Case ID
```
Type in search: "CASE-001"
Result: Applications with CASE-001 in ID
```

## 🆘 Troubleshooting

### Issue: No applications in Tab 2
**Solution:** Submit an application in Tab 1 first

### Issue: Search not working
**Solution:** Check spelling, use correct ID format

### Issue: Download doesn't work
**Solution:** Check browser settings, allow downloads

### Issue: Can't see all 4 tabs
**Solution:** Refresh page, check browser window size
