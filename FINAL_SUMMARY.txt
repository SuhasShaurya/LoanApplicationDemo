  $ python3 test_loan_decision.py
  Expected: TEST SUMMARY: 7 passed, 0 failed ✓

Step 2: Start Backend API (Terminal 1)
  $ python3 main.py
  Expected: Uvicorn running on http://127.0.0.1:8000

Step 3: Start Frontend UI (Terminal 2)
  $ streamlit run ui/streamlit_app.py
  Expected: Opens http://localhost:8501 in browser

Step 4: Fill Application & Submit
  - Open UI at http://localhost:8501
  - Click "📋 Apply for Loan" tab
  - Fill in example data:
    * Applicant ID: APP001
    * Age: 35
    * Annual Income: 85000
    * Employment Type: Full-time
    * Credit Score: 760
    * Loan Amount: 200000
    * Loan Tenure: 360
    * Existing Liabilities: 2500
    * Location: California
  - Click "Submit Application"

  - Decision type (✅ Approve)
  - Risk score (0.15)
  - Confidence (88%)
  - Explanation
  - Key factors
  - Financial details
  - Download options
